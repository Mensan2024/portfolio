gateway-lan-wan · iptables
# tout est refusé par défaut
$ iptables -P INPUT DROP
$ iptables -P FORWARD DROP
# on autorise seulement les réponses
$ iptables -A FORWARD -m state --state ESTABLISHED,RELATED -j ACCEPT
# partage de la sortie WAN pour le LAN
$ iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
# le reste est tracé
$ iptables -A INPUT -j LOG --log-prefix "DROP: "
✓ règles persistantes au redémarrage

Défense en profondeur

  1. SegmenterVLAN et zones LAN/WAN séparés
  2. Restreindrepolitique « tout refuser » par défaut
  3. Journaliserchaque refus laisse une trace
  4. Testerchaque changement validé en lab
  5. Documenterpour que l’équipe reprenne la main
